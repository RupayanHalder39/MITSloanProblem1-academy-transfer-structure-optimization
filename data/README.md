# Data availability

No raw, row-level, or player-level source dataset is redistributed in this
repository. The available source documentation does not establish permission
to republish the underlying valuation histories, transfer ledger, academy
workbook, or club export.

The repository includes only small, publication-facing aggregate result files
under `results/`. They are sufficient to verify the numerical statements in
the paper and README, but not to retrain the forecast or rerun the complete
36-exit optimization.

Researchers with lawful access to equivalent source data can reconstruct the
analytical inputs by following `docs/DATA_PROVENANCE.md` and the definitions in
`docs/METHODOLOGY.md`. The public package intentionally does not provide a way
to bypass third-party access or licensing conditions.
